# Sample stories

## The Last Lighthouse

A five-chapter branching demo with three endings, a `trust_elena` flag, and
a choice that only appears when the reader has earned Elena's trust. Uses
the rich-text formatting (`*italic*`, `**bold**`) supported in narration
and dialogue blocks.

### To load it

1. In the author dashboard, create any new story (title doesn't matter —
   the import creates a fresh draft).
2. Alternatively: on any existing story, open the header link
   **Import / Export**.
3. Open `samples/lighthouse.forkedtales.json`, copy the whole file, and
   paste it into the **Import** textarea.
4. Click **Import as new draft** — you'll be dropped into the imported
   story's edit page.
5. Flip the story's **Status** from `draft` to `ongoing` and hit **Save
   details**, then click **Preview →** to read it.

The three endings will fill in on the story landing page's **Endings**
tab as you discover each branch. The **Branch tree** tab will grow as
you visit chapters, and the currently-locked "Climb with Elena" choice
will remain hidden on the first pass unless you pick **Believe her** in
chapter 2.
